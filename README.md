# Bingo

Letni bingo ciljev: mreža nalog za celo leto, ki jih sproti kljukaš. Za
naslednje leto lahko že vnaprej narediš novo tablo.
Next.js 16 + Supabase, deploy na Vercel.

```bash
npm install
cp .env.example .env.local   # vpiši Supabase URL in anon ključ
npm run dev                  # http://localhost:3008
```

Podrobnosti v `CLAUDE.md`.
